## 채택과 보류 기준

- 목록의 최저가나 쿠폰·포인트 적용 금액을 가져오지 않고 직접 연 상세의 공개 옵션 가격을 사용했다. 여신티켓은 `detail.salesProducts[].price`, 강남언니는 `serviceOffer.options[].price.discountedAmount`, 바비톡은 `eventData.discount_price`다.
- 여신티켓은 구매 가능·미종료 상태, 해당 옵션 `view=true`, 1회·KRW, VAT 포함과 실제 표시 가격을 확인했다. 기본 정보에 숨겨진 옵션이 남아 있으면 제외했다.
- 강남언니는 제공 가능, 단일 시술·1회, VAT 포함·명시된 추가요금 없음, 옵션의 제한 배지 없음 조건을 확인했다. 여러 시술 묶음이나 회차 불명 상품을 1회로 환산하지 않았다.
- 바비톡은 VAT 포함, 단일 공개 가격 유형과 표시 금액·비종료 상태를 확인했다. 옵션 ID·회차가 명시되지 않은 경우 null로 보존하고 ‘횟수 미기재’ 조건으로 분리했다.
- 첫 방문·체험·재방문·한정 조건, 복합 패키지, 추가요금 조건 차이, 공개 여부/과세/단위/표시 가격을 확인할 수 없는 항목은 보류했다. 동일 플랫폼·동일 제공자·동일 가격 조건의 중복은 1표본만 남겼다. 당일 같은 조건에 다른 금액이 있으면 임의로 최저가를 고르지 않고 해당 표본을 보류했다.
- 사이트 사이 동일 제공자임을 완전히 확인할 수 없는 자료는 **플랫폼을 비교 조건에 포함**해 별도로 표시한다. 사이트 간 표본을 중복 가능성 확인 없이 하나의 통합 평균으로 계산하지 않는다.
- 장비, 제품, 샷 수, 용량, 관리 시간, 부위, 회차, 플랫폼이 다르면 별도 조건이다. 옵션에서 확인되지 않는 속성은 ‘미기재’로 남긴다. 이 분류가 시술 프로토콜 전체의 동일함을 보장하지 않으며 추가 관리·팁·주입 방식·최종 결제 금액은 별도 확인이 필요하다.

모든 자료는 공개 검색 편의 표본으로 지역·플랫폼·검색 순위·할인 노출 편향이 있다. **전국 평균·적정가·시술 효과·의료진 검수를 확인한 자료가 아니다.** 의학적 원리나 부작용 안내는 이번 수집에서 새로 확대하거나 승인하지 않았다.

## 앱 반영

기존 JSON 가격 관측 배열과 DB 열을 재사용했다. 스키마 마이그레이션은 없다. 기본 조건의 기존 `priceMinKrw`·`priceMaxKrw`·`priceSummary`는 유지하고, 조건별 계산 결과만 가진 선택적 `priceOptions`를 공개 DTO에 추가했다. 원본 URL·표본 키·병원/의료진 식별 정보는 공개 API에 포함하지 않는다.

`summarizeProcedurePrices`의 단일 조건 엄격 검증은 유지한다. 새 `summarizeProcedurePriceOptions`가 조건을 분리한 뒤 각각 같은 검증·중복 제거·VAT 정규화·평균 계산을 적용한다. 서로 다른 조건을 통째로 평균 내지 않으며 잘못된 출처·미래 날짜·충돌 가격은 계속 거부한다. 기존 단일 조건/가격 미확인 데이터도 지원한다.

기존 시술 목록에는 기본 조건과 조건 수를 표시한다. 상세 모달과 안전 상세의 가격 영역에는 키보드로 조작 가능한 ‘가격 비교 조건’ 선택을 제공한다. 각 조건의 범위·표본 평균 또는 단일 관측값·표본 수·부가세·플랫폼·확인 기간이 함께 바뀐다. 한 표본을 시장 평균처럼 표시하지 않는다.

게시용 읽기 전용 카탈로그는 새 버전 JSON을 사용한다. 로컬 DB도 기존 `procedures:prices -- <file> --apply`로 갱신했으며 명령의 로컬 전용 검증을 유지했다. 운영 DB·환경·새 채팅의 작업을 덮어쓰지 않는다. 공개 배포나 main push는 이번 작업에서 수행하지 않는다. 기존 환경을 보존하며 원본 `8b4c542`의 미복구 기록을 유지한다.
