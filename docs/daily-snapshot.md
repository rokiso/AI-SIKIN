# 데일리 피부 스냅샷

`/snapshot`에서 로그인한 회원이 카메라 또는 앨범 사진을 한국 시간 기준 하루 한 번 기록합니다. 사진은 기존 전처리로 회전 보정·1280px 최적화하며 업로드 진행률과 완료 재시도를 제공합니다. 카메라는 닫거나 촬영을 완료하면 종료합니다.

## API와 소유권

- `POST /api/v1/snapshots/upload-url`: 검증된 회원 쿠키로 업로드 세션을 만들고 300초 PUT URL을 반환합니다. 키는 `daily-snapshots/snp-UUID.jpg`이며 시간당 발급 한도는 3회입니다.
- `POST /api/v1/snapshots`: `s3Key`, `etag`, `idempotencyKey`를 받습니다. 서버가 소유권·한국 날짜·유효기간과 실제 객체의 크기·MIME·ETag·AES256 암호화를 확인합니다. 최초 저장은 201, 같은 완료 요청 재전송은 200입니다. 같은 날짜의 다른 기록은 409입니다.
- `GET /api/v1/snapshots/today`: 현재 회원의 오늘 기록과 300초 비공개 조회 URL을 반환합니다. 응답은 캐시하지 않습니다.

회원·날짜별 트랜잭션 잠금과 DB 고유 제약으로 동시 요청도 한 건만 저장합니다. 클라이언트 userId나 헤더는 신원으로 사용하지 않으며 쓰기 요청은 동일 출처만 허용합니다.

## AI 미연결 시 동작

기본값은 `GENERAL_GUIDANCE`입니다. AI 분석을 수행하지 않았음을 표시하고 일반 관리 안내만 제공하며 보습·진정·유분 수준을 추정해 표시하지 않습니다.

선택적으로 서버 환경의 `SNAPSHOT_AI_API_KEY`, `SNAPSHOT_AI_MODEL`을 함께 설정하면 OpenAI Responses API에 제한된 구조의 사진 참고 피드백을 요청합니다. 시간 제한·오류·잘못된 응답에는 일반 안내로 전환합니다. 제공자가 얼굴 없음을 명시하면 저장을 거절합니다. 일반 안내 모드에서는 얼굴 검출을 수행하지 않습니다. AI 결과는 측정값이나 의료 진단이 아닙니다.

실제 AI 키·모델과 제공자 호환성은 검증하지 않았습니다. 실제 사진으로 외부 AI 호출을 수행하지 않았습니다.

## 나중에 공개 반영할 때

이번 작업은 로컬 초안이며 공개 배포나 운영 DB 변경을 수행하지 않았습니다. 배포 전 기존 데이터가 있는 DB에 추가 마이그레이션 `20261115000000_snapshot_recording`을 적용해야 합니다. 기존 마이그레이션 변경·운영 DB 초기화·초기 생성 SQL 재실행은 하지 않습니다.

사용자는 AWS/S3 실연결을 보류했습니다. 실제 업로드에는 기존 보관소 환경 설정 외에 `daily-snapshots/*` 경로의 최소 PUT·HEAD·GET 권한과 브라우저 CORS 설정을 확인해야 합니다. 기존 진단 사진의 `raw-faces/*` 권한만으로는 충분하지 않습니다. 비공개 버킷과 공개 접근 차단을 유지합니다. 비밀 값은 저장소에 넣지 않습니다.

## 검증 범위

단위 89개, 실제 로컬 Postgres DB 45개, 브라우저 39개 및 lint·typecheck·build·기존 format 검사 통과. 하루 중복·소유권·멱등 재시도·한국 날짜 경계·객체 검증과 320px/1280px 화면, 카메라 트랙 종료를 포함합니다. 브라우저 사진은 합성 이미지이며 스토리지와 AI 응답은 모의 처리했습니다. 실제 S3 전송·휴대폰 카메라·실제 소셜 제공자 로그인을 검증한 결과는 아닙니다.
