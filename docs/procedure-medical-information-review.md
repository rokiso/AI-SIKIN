# 시술 10종 의학 정보 자료 검토

검토일: 2026-11-19 (한국 시간). 대상: 커밋 `3745568`의 `prisma/seeds/procedures.ts`, `prisma/seeds/procedure-safety.ts`, 시술 상세 페이지와 위험 안내 컴포넌트. 작성 주체: AI 코딩 도구. **실제 의료진의 임상 검수가 아니다.**

사용자는 의료진/제품 설명서가 정해지지 않았음을 확인하고 “그럼 검토만 하자”로 범위를 정했다. 따라서 이번 결과는 10종 모두에 대해 문구·일반 근거·미확인 항목을 정리한 자료 검토다. 공개 사이트/운영 DB의 최신 내용을 직접 확인한 검토, 개인의 적응증 판정, 국내 허가 검증 또는 제품별 안전성 보증으로 사용하지 않는다. 기존 가격 수집 작업의 대표성도 검증하지 않는다.

## 결과와 판단 기준

10종 전체의 원리, 적응증으로 오해할 표현, 위험, 시술 전 확인 사항, 회복·사후 관리, 상담 질문을 읽었다. 확보한 자료는 일반 안내를 부분적으로 뒷받침하지만, **어느 시술도 제품·장비별 검증 및 의료진 검수를 완료한 것으로 표시할 수 없다.**

- 현재 안내는 획일적 주기·약물 중단·용량·효과 보장 대신 의료진에게 확인하도록 되어 있다. 이번에 읽은 자료와 직접 충돌하여 즉시 삭제해야 한다고 판단한 문구는 없었다. 이는 위험 목록이 완전하거나 모든 문구가 직접 근거로 입증됐다는 의미가 아니다.
- PN·LDM·아쿠아필은 이번 확보 자료에서 해당 제품/장비의 직접 근거를 확인하지 못했다. 피코도 기미·레이저 일반 자료를 피코토닝의 개별 적응증·파장·반복 간격에 대한 근거로 바꿀 수 없다.
- 프락셔널의 감염·색소침착 등 개별 위험과 HIFU의 지방 위축 등은 이번 일반 자료만으로 모두 검증되지 않았다. 제품별 사용설명서와 별도 문헌 검토가 남아 있다.
- RF 미세침의 흉터·신경 손상 등 중대한 보고는 기존 위험 목록에서 구체적으로 다루지 않는다. 비침습 RF와 구분한 설명 보완이 필요하다. 기존 문구가 “화상·지방 위축”을 언급한다고 전체 RF 위험 안내가 완결되는 것은 아니다.
- 시술 고민 태그는 개인의 적응증이 아니라고 화면에 명시되어 있다. HA가 BARRIER_REDNESS에 연결돼 있다는 사실로 홍조·장벽 치료 효과가 입증됐다고 해석해서는 안 된다.

## 공통 표현과 후속 편집 권고

1. **약물은 스스로 중단하도록 안내하지 않는다.** S3·S10에 특정 약물이나 기간이 나오더라도 현재 사용자의 약/질환·시술을 모르는 상태에서 일괄 처방으로 옮기지 않는다. 현재 “복용·도포 약을 알리고 의료진에게 확인” 문구를 유지한다.
2. 레이저/박피 상담 질문에 과거 헤르페스, 흉터/켈로이드 경향, 광민감성·최근 태닝 여부를 상황에 맞게 보완할 수 있다. 전체 시술의 절대 금기라고 묶어 표시하지 않는다.
3. 주입 후 시야 변화·비정상 통증·피부색 변화는 의료기관에 연락만 하며 기다리는 표현으로 약화하지 않는다. HA의 기존 즉시 진료 안내는 유지한다. PN 제제의 제품별 대응은 별도로 확인한다.
4. 위험 발생률, 회복 기간, 샷 수/용량·시술 주기, 효과 크기는 이번 자료로 숫자를 새로 만들지 않는다. S11의 치료 횟수/효과 수치도 개별 PDL 상품에 그대로 넣지 않는다.
5. 공통 면책 문구는 근거 부족을 대체하지 않는다. `readiness=READY`는 현재 필수 데이터 존재 여부이지 의학적 검토 상태가 아니다. 이번 검토로 임상 승인 배지나 “의료진 검수 완료”를 추가하지 않는다.
6. 가격 적합성과 의학적 적합성은 다르다. 가격이 낮거나 표본이 많다는 이유로 시술 필요성·안전성을 추천하지 않는다. 상담 질문의 대안·총비용·사후 대응 확인은 유지한다.

사용자가 이번에는 검토만 요청했으므로 위 보완 권고를 프로덕션 코드·시드·DB에 적용하지 않았다. 운영 반영 전에는 범주별로 근거를 연결해 문구를 편집하고 저장된 DB 자료와 공개 자료 양쪽을 갱신·검증해야 한다. 현재 시드는 기존 행을 덮어쓰지 않으므로 시드 파일 수정만으로 기존 DB 문구가 바뀌었다고 가정해서는 안 된다.
