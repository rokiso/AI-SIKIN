## 실제 서비스 연결 확인의 한계

환경 상태 도구의 현재 관측은 선택된 환경 ID와 일치했고 `observations_current=true`였습니다. 연결된 outbound identity와 환경 시크릿/런타임 변수 목록은 비어 있습니다. 런타임에서도 `S3_VAULT_BUCKET`, `S3_VAULT_REGION`, AWS 자격증명, AI 키·모델, Vercel 관리 토큰이 없었습니다. AWS 연결 manifest v1의 AWS identity와 구성/자격증명 프로파일도 0개입니다. 값이나 키를 문서에 기록하지 않았습니다.

따라서 대상 버킷의 Lifecycle·Versioning·Object Lock·복제/백업, 현재 IAM 권한, 삭제 작업의 운영 실행·실패/재시도 기록과 실제 객체 제거를 확인할 수 없습니다. 저장소에 설정 파일이 없다는 이유만으로 외부 AWS 계정에도 설정이 없다고 단정하지 않습니다. 반대로 미접속 상태를 확인 완료로 취급하지도 않습니다.
