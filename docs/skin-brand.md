# SKIN 브랜드 표기와 주소

화면 로고·접근성 이름·탭 제목·로그인 제목·상품 일러스트·체험 브랜드·제휴 고지와 PWA name/short_name, iOS 설치 제목을 SKIN으로 통일했습니다. 아이콘은 기존 잎 모양을 유지하면서 새 skin-* 경로를 사용합니다. 이미 설치된 앱이 이전 자산 경로를 요청할 수 있으므로 기존 sikin-* 경로도 호환용으로 남깁니다. manifest id/start_url/scope는 유지합니다.

기존 로그인·게스트 세션을 무효화하지 않도록 쿠키·서명 네임스페이스, DB 이름, 저장소 주소 등 내부 식별자를 일괄 변경하지 않습니다. 저장소 이름을 바꾸는 작업은 이 변경에 포함하지 않습니다.

## 주소 변경에 필요한 후속 작업

현재 공개 주소는 `https://ai-sikin.vercel.app`입니다. `https://ai-skin.vercel.app`는 사용자가 원하는 수정 후보이지, 사용 가능하거나 이 프로젝트에 연결됐다고 확인한 주소가 아닙니다. 이 환경에는 Vercel 계정 접근 도구나 자격 증명이 없어 프로젝트 이름/도메인/별칭을 직접 변경하지 못했습니다. 코드만 바꾸어 vercel.app 주소를 등록할 수는 없습니다.

Vercel의 해당 프로젝트 설정에서 이름/도메인 항목을 확인해 새 주소를 확보하고 현재 프로젝트에 연결해야 합니다. 사용 중인 주소면 다른 이름을 선택해야 합니다. 기존 주소는 새 주소의 정상 연결을 확인하기 전 제거하지 않습니다. 실제 소셜 로그인을 설정할 때는 승인된 새 주소에 맞춰 앱 기준 URL과 Google/Kakao 콜백 허용 주소도 함께 확인해야 합니다.

앱을 새 주소로 설치하면 출처가 달라지므로 기존 설치나 로그인이 자동으로 새 출처로 옮겨지는 것으로 안내하지 않습니다. 기존 설치 이름의 갱신 방식은 기기/브라우저에 따라 달라 별도로 확인해야 합니다.

이번 공개 브랜드 배포는 기존 공개 버전만 기반으로 하며, 별도 로컬 카메라 초안 d364996은 포함하지 않습니다.
