# 스킨케어 입문 가이드

홈과 화장품 화면에서 **스킨케어가 처음이라면**을 선택하면 `/catalog/products/guide`로 이동한다. 로그인·사진·진단 이력이 없어도 제품 역할, 사용 순서와 보습 조절을 배울 수 있다. 기존 화장품 탭과 뒤로 가기, 의료 면책 고지를 재사용한다.

## 제공하는 내용

- 클렌저, 토너, 앰플·세럼·에센스, 로션·젤크림·크림, 자외선 차단제의 역할을 펼쳐볼 수 있다. 토너·앰플은 선택 단계로 설명한다.
- 아침과 저녁을 선택하면 기본 순서가 바뀐다. 선택 제품의 순서를 켜면 토너·앰플 단계가 추가되며, 개별 제품 안내가 우선임을 설명한다. 별도 클렌저나 이중 세안을 일괄 의무화하지 않는다.
- 번들거림, 당김, 둘 다, 잘 모름과 덥고 습함, 춥고 건조함, 실내 환경의 12가지 조합으로 보습 힌트를 살펴본다. 피부 타입을 확정하거나 진단 결과를 저장하는 기능은 아니다.
- 건조한 공기에서 수분이 빠져나가 당길 수 있고, 습하고 더운 환경에서는 같은 제품도 무겁게 느껴질 수 있음을 설명한다. 계절에 따른 의무 구매·교체 대신 양·횟수·제형을 필요에 따라 조절하고 편안한 제품은 계속 쓰도록 안내한다.

## 구현 경계

제품 역할과 페이지 구성은 서버 컴포넌트·정적 데이터로 제공하고, 루틴과 보습 선택만 작은 클라이언트 컴포넌트로 분리한다. 선택값은 React 메모리에만 있으며 새로고침 시 초기화된다. 저장 API·브라우저 영구 저장소·외부 AI 호출·새 DB 스키마·패키지를 추가하지 않는다. 기존 추천 점수, 제품 데이터와 구매 링크 계약을 변경하지 않는다.

사용자 제공 영상 자막은 설명 주제의 참고 자료로 사용했다. 설명은 독립적으로 작성했으며 특정 제품, 성분 함량, 가격·환불 조건이나 ‘피부 고민 90% 해결’ 같은 미검증 주장은 옮기지 않았다. 고가·고함량·제품 명칭만으로 우열을 정하지 않는다.

보습·건조한 환경·자외선 보호에 관해서는 AAD의 공개 안내 본문을 교차 확인했다:
https://www.aad.org/public/everyday-care/skin-care-basics/dry/dermatologists-tips-relieve-dry-skin

이는 개별 제품의 효능 검증이나 개인별 의료 조언이 아니다.
