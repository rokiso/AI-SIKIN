# 마이페이지 이력 보관함

기존 /mypage 프로필·로그인·로그아웃·데일리 기록 링크 아래에 피부 진단 이력과 데일리 기록 탭을 연결합니다. 이미 구현한 S3 업로드 작업을 중복 구현하는 대신, 사용자가 저장된 결과를 다시 확인할 수 있도록 우선 작업했습니다. 신규 테이블·마이그레이션·외부 계정·의존성은 없습니다.

## API 및 인가

GET /api/v1/users/me/history. tab=diagnostics|snapshots|all(기본all), limit=1~50(기본20), cursor=이전페이지마지막ID(UUID). 각 컬렉션에 totalCount/items/nextCursor를 제공합니다. cursor는 단일탭에서만 사용하며 all+cursor는 거절합니다. 중복/미지원쿼리와 userId선택도400으로 거절합니다.

기존 실회원 세션 DB검증 및 HttpOnly 서명 게스트를 재사용합니다. 원시 게스트UUID헤더는 신뢰하지 않습니다. 회원은 본인 리포트·사진만, 게스트는 userId=null인 본인 완료 리포트만 조회합니다. 미완료 문진 세션을 완료된 분석 리포트로 표시하지 않습니다. 커서는 먼저 본인 소유를 검증한 후 날짜·ID 경계로 사용합니다. 같은 시각에 생성된 리포트도 ID 정렬로 누락·중복 없이 페이지를 넘깁니다.

응답은 private,no-store/Vary:Cookie입니다. 타입·4축점수·요약·성분만 조회하며 내부AI감사메타데이터와 원본s3Key는 필드에 포함하지 않습니다. 이메일은 이 화면에서 사용하지 않아 null로 가립니다. 종합점수는 DB에 저장된 정의가 없으므로 임의 산출하지 않고 overallScore=null로 반환합니다.

사진 탭에서만 기존 snapshotView와300초GET서명을 사용합니다. S3설정이나 사진 테이블 문제로 사진 조회가 실패해도 진단 탭의 조회는 독립적으로 동작합니다. GENERAL_GUIDANCE는conditions=null로 보내 기본BALANCED값을AI측정으로 표시하지 않습니다. 원래 설계의 불투명한500 대신 일시 조회불가503과 안전한 에러엔벨로프를 반환합니다.

## 화면·기존 결정 반영

이전 사용자 요청에 따라 영문 바우만코드는 UI에서 숨기고 한글 설명을 사용합니다. 색소침착/고민적음 표현을 유지하며 저장된 내부16코드는 변경하지 않습니다. 기존 SkinSummaryCard에 제목/이력링크표시 옵션만 추가해 상세모달에서 재사용하고, 공통면책도 함께 표시합니다. 네이티브dialog로 포커스가 갇히고 Escape/닫기 후 원래카드로 복귀합니다.

리포트 카드에는 KST일시·한글특성·요약·4축미니막대, 상세에는 점수·주의/권장성분을 표시합니다. 탭은 좌우/Home/End키를 지원합니다. 로딩·빈결과·조회실패·더보기실패재시도·게스트사진가드를 구분합니다. 실패를 빈데이터로 숨기지 않습니다. 탭전환/언마운트시 이전요청을 취소해 늦은응답이 현재탭을 덮지 않도록 합니다. 더보기중 중복요청을 차단하고 기존카드를 유지합니다. 사진새로불러오기는 첫페이지를 재조회하여 만료URL을 갱신합니다.

분석서비스가 연결되지 않아 문진답변만 저장한 경우에는 완료리포트가 없을 수 있음을 빈상태에 안내합니다. 실제사진보관과 소셜로그인은 기존운영설정 범위이며, 임의샘플리포트·진단·상품을 실제기록으로 보여주지 않습니다.

## 검증 및 운영 범위

실제 로컬PostgreSQL에서 회원/서명게스트/타인/만료·폐기세션/미완료리포트/동일시각정렬/페이지경계/타인커서·ID주입/사진일자/저장소장애격리를 검증합니다. 브라우저에서는 개인정보없는 모의결과로 오류재시도·페이징·상세모달·포커스복귀·탭·일반안내·게스트가드를320/375/430/1280px에서 검증합니다. 실제계정·운영DB·실제S3·AI·유료자원은 변경하지 않았습니다. 이번 작업은 공개배포하지 않습니다.
