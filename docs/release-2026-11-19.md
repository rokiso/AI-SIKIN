## 운영 활성화 경계

`ACCOUNT_DELETION_ENABLED`는 기본 OFF다. 마이페이지에서 미활성 탈퇴 버튼을 노출하지 않고 준비 중임을 알리며, DELETE 서비스와 기록 수 조회 API도 503으로 중단한다. 외부 사용자가 API를 직접 호출해도 설정을 우회할 수 없다. 운영 활성화에는 신규 마이그레이션, 실제 버킷의 버전/마커/백업 및 권한, 부분 실패·재시도·지연 업로드 재생성 방지 확인이 선행되어야 한다. 브라우저 저장형 프로젝트와 로컬 DB 테스트에서만 명시적으로 켜서 합성 계정으로 검증한다.

기존 실제 AI/OAuth·S3 연결, 비회원 24시간/진단 직후 사진 삭제, 약관 활성화는 새로 켜지 않는다. 실제 판매 상품의 공식 전성분 50~100개를 새로 확보했다고 주장하지 않는다. 가격 표본은 전국 시장 대표 시세가 아니며, 부족한 표본을 임의의 가격으로 채우지 않는다.

운영 DB 연결/신규 마이그레이션 적용은 수행하지 않는다. 기본 시술 원본은 기존 Vercel의 published 자료이며, 체험 화장품은 DB 없는 안내를 유지한다. 초기 4개 마이그레이션만 있는 일회용 로컬 DB로 주요 경로와 비활성 삭제 API의 호환성을 별도 확인한다.
