# 운영 DB 및 시술 상세 활성화 기록 — 2026-11-25

앱 소스는 `988a1663a3369e5e0ff4c0f099db92be8273d720`이다. 이 디렉터리는 사용자가 Neon/Vercel 콘솔에서 수행한 운영 변경과 검증 증거를 보존한다. 앱 시작이나 빌드에서 이 SQL을 자동 실행하지 않는다.

## 적용한 변경

- Neon `ai-skin-db`의 운영 `main`에 초기 4개 migration이 있음을 사용자 화면으로 확인했다.
- `main`에서 `backup-before-migration-2026-11-25`를 만들고 자동 삭제를 Never로 설정했다. 보관 방식은 Neon의 데이터·스키마 브랜치 복사이며 외부 pg_dump 반출은 수행하지 않았다.
- 보관용 브랜치에서 `migration-test-2026-11-25`를 만든 뒤 먼저 16개 완료 상태로 올렸다. 검증 후 운영 `main`에도 동일한 실행 본문을 적용했다. 보관용 브랜치는 초기 상태로 유지했다.
- 사용자가 Vercel `ai-skin`의 Production에 `PROCEDURE_SAFETY_ENABLED=1`을 추가하고 기존 main 소스로 재배포했다. 실제 공개 API와 화면에서 활성화를 확인했다.

운영 migration 적용은 사용자 제공 Neon 결과 화면에 근거한다. 에이전트가 운영 DB 자격 증명으로 직접 접속한 작업과 구분한다. 운영 Vercel 설정도 사용자 콘솔 작업으로 이루어졌다.

## SQL 및 무결성

[운영 적용 SQL](applied-main.sql)과 [검증용 SQL](rehearsed-test.sql)은 당시 실행한 78줄 파일이다. 첫 안내 주석만 다르고 실행 본문은 동일하다. 각 원본 migration의 SQL을 JSON 안에 그대로 보관하고, 서버에서 원문 SHA-256을 검사한다. 96줄 이내로 전달하기 위한 형식이며 파일의 일부만 별도로 실행하는 형식이 아니다.

초기 4개 이력과 체크섬, 미해결 이력, NULL 제품 성분, 카테고리별 2개 초과 추천 그룹을 확인한다. 원본 12개를 단일 원자적 DO에서 실행하고 실제 적용한 파일의 완료 이력을 같은 작업 안에서 기록한다. 오류가 나면 해당 DO 전체가 취소된다. 이미 동일한 16개가 완료된 경우에는 DDL을 재실행하지 않는다. 일부 적용·체크섬 변경 등 예상과 다른 상태에서는 중단한다. 앱 플래그 변경이나 약관 활성화는 SQL에 포함하지 않는다.

이 SQL 자체가 Neon 브랜치 이름을 강제하지는 않는다. 실제 적용 대상은 사용자 화면에서 확인했다. 이 파일은 당시 적용 기록이며, 이후 다른 DB나 새 스키마에 적용할 때에는 대상·백업·현재 이력을 다시 검토해야 한다.

## 검증 범위

- 직접 만든 로컬 임시 DB 8개에서 검증했다. 원래 SQL을 Prisma migrate deploy로 적용한 DB와 컬럼·인덱스·제약·enum·trigger가 일치하고, Prisma migrate status가 16개 완료 이력을 정상 인식했다.
- 합성 기존 행·필드 보존, 제품 성분/추천 tier backfill, 재실행 안전성, 비활성 동의 초안을 확인했다. 잘못된 체크섬·중간 컬럼 충돌·3개 추천 그룹·NULL 성분·변경된 payload에서는 전체 변경 취소를 확인했다. 검사 후 직접 만든 로컬 임시 DB만 정리했다.
- 공개 사이트의 10종 상세 API가 200/READY, 상세 페이지가 200이며 부작용·위험·금기·사후 관리·상담 질문 3개와 면책 안내를 제공함을 확인했다. 기존 가격 260건·102조건과 목록 링크 10개도 유지됐다.
- 320/1280px에서 실제 공개 응답으로 화면을 렌더해 네이티브 클립보드에 질문 3개가 복사되는지, RF 미세침/비침습 구분 경고, 가로 넘침 없음, main 접근성 위반 0 및 페이지 오류 0을 확인했다. Chromium의 관리 CA 차이를 처리하기 위해 Node HTTPS의 인증서 검증을 유지하고 원래 공개 응답을 내용 수정 없이 전달했다.
- 이전 소스 커밋 `988a166`의 개발 검증 657개 통과 기록은 이전 배포 기록에 있다. 이번 기록 저장에는 앱 기능 코드를 변경하지 않았다. 상세 결과는 [검증 기록](verification.json), 원본 체크섬과 적용 출처는 [manifest](manifest.json)에 있다.
