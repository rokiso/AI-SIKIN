# 2026-11-18 전체 작업 공개 반영 및 저장

사용자가 공개 배포와 오늘까지의 작업 저장을 승인했다. 기존 공식 주소는 https://miruvia.vercel.app 이며, GitHub `rokiso/AI-SIKIN`의 main 갱신으로 기존 Vercel Git 자동 배포를 요청한다. 환경 설정 게시와 서비스 공개 배포를 구분한다.

## 이번 저장 범위

기존 main `1e9a8f9` 뒤의 문진 기반 진단 결과와 실제 서버 진행 SSE, OAuth 설정 검사, 버전별 사진 동의 차단, 실제 보관·삭제 감사, 시술 10종 및 세 플랫폼 가격 표본을 모두 보존한다. 시술 표본은 21건/고유 20개이며, 표본 수·시술 단위·확인이 필요한 횟수/추가비용을 명시한다. 원본 `8b4c542` 복구와 그 후 재구현한 작업은 구분한다.

배포 전 다음 호환성 수정을 추가했다.

- 공개 Vercel의 시술 가이드는 저장소에 검증·고정된 2026-11-18 자료를 읽는다. 운영 DB의 새 시술 열이나 가격 시드에 의존하지 않으므로 해당 운영 스키마를 변경하지 않고 10종과 실제 표본을 표시할 수 있다. 서버에서 기존 공개 DTO 검증·가격 계산·비공개 원문 URL 제거를 공유한다.
- `VERCEL=1`에서는 시술 데이터 원본이 `published`, 다른 환경은 `database`가 기본이다. 필요하면 서버 환경 변수 `PROCEDURE_CATALOG_SOURCE=published|database`로 명시한다. 잘못된 값은 오류로 처리한다. DB 오류를 숨기고 임의 전환하는 폴백은 아니다. API의 `X-Procedure-Catalog-Source` 헤더로 선택된 원본을 확인할 수 있다.
- 게시 자료의 시술 URL ID는 고정되며, 로컬 DB의 UUID와 구분된다. 운영 DB 방식으로 전환할 때는 스키마·자료·URL 호환성을 먼저 검증한다.
- 구형 동의 테이블에는 비회원 식별자 열과 비회원 동의 기록이 없다. 로그인 시 이관 대상이 존재할 수 없는 구형 스키마에서는 이관을 0건으로 처리한다. 새 스키마의 기존 동의 이관과 사진 전송 전 최신 동의 검증은 유지한다. 초기 스키마에서 재현한 P2022 로그인 실패를 해결했다.
- 새 CI DB에 가격 자료를 준비하는 단계를 추가했다. 로컬 전용 가드를 유지하고 실제 공개 이벤트 JSON을 명시적으로 읽는다. 브라우저 검사는 DB 방식과 게시 자료 방식 모두 수행한다.

## 유지되는 제한

사진의 실제 S3 저장·24시간 자동 파기·탈퇴 시 완전 삭제 및 운영 정책 검증은 미완료다. 약관은 비활성 상태를 유지하며, 저장 기간이나 자동 파기를 구현된 기능처럼 약속하지 않는다. 실제 공급자 AI·OAuth 연결과 자격증명을 새로 활성화하지 않는다. 데이터가 미설정인 경우 기존 기기 내 사진 체험과 문진 기반 안내를 유지한다.

가격 표본은 전국 시장 대표 평균이 아니며, 일부 공개 상품의 정확한 횟수·총비용은 미확인이다. 이 제한을 화면과 작업 보드에 유지한다. 게시 자료의 갱신은 검증된 데이터 파일을 수정하고 다시 배포하는 절차이며, 실시간 가격 수집을 주장하지 않는다.
