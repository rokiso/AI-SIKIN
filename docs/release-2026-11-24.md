## 저장과 공개 확인

배포 전 저장소 밖에 Git bundle과 검증 로그·화면·영수증을 보존하고 bundle 복원 HEAD가 배포 대상과 같은지 확인한다. 개인 MCP 설정·API 키·`.env`는 bundle에 포함하지 않는다. GitHub main에 non-force push한 뒤 원격 SHA 일치를 확인하고 기존 Git 연동 Vercel 배포의 실제 공개 응답을 확인한다.

공개 배포 판별에는 새 마일스톤 API가 HTML 404 대신 표준 JSON 401을 반환하는지, 기존 홈·시술·마이페이지·스냅샷이 정상인지 확인한다. 운영 회원 계정의 달성 리포트 발급이나 운영 마이그레이션을 확인했다고 표시하지 않는다. Vercel 관리 콘솔 Ready는 접근할 수 없으므로 실제 공개 응답 검증과 구분한다. 최종 SHA·백업 경로·원격/공개 결과는 저장소 밖 배포 영수증과 작업 보드에 기록한다.
