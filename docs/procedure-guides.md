## 가격 수집: 세 플랫폼의 공개 표본 반영

2026-11-18 새 게시 환경의 enforced 허용 목록과 실제 요청을 확인했다. `https://unni.app/`와 바비톡 공개 검색 API `https://web-api.babitalk.com/v2/search/events/summary` 모두 HTTP 200이다. 이전의 두 호스트 차단은 해소됐다. 에이전트가 환경 설정을 다시 적용하거나 게시하지 않았다.

기존 여신티켓 15건을 보존하고 강남언니 1건, 바비톡 5건을 추가했다. **총 21건, 동일 제공자의 LDM 중복을 제외한 20개 표본**이다. PN은 세 플랫폼, RF는 여신티켓·바비톡에서 비교 가능한 용량/샷 수 금액을 확보했다. 다른 항목은 아직 여신티켓 표본만 있으며, 모든 시술을 세 플랫폼에서 조사했다고 주장하지 않는다. 원본 근거와 보류 이유는 `data/procedure-prices/2026-11-18/evidence.json`에 기록했다.

공개 이벤트 할인과 개인 혜택은 구분했다. 여신티켓은 본문 `detail/salesProducts[].price`, 강남언니는 선택 옵션의 `price.discountedAmount`, 바비톡은 공개 `eventData.discount_price`를 읽었다. 이들은 쿠폰·포인트 차감 전 공개 표시 금액이며, 원가/취소선 가격이나 앱 설치 포인트를 실결제 금액처럼 계산하지 않는다. VAT 포함 여부를 각 소스에서 확인했다. 첫 방문·재방문·특정 요일·1인1회 한정 및 추가 관리 포함 조건이 다른 옵션은 따로 보류했다.

## 수집 및 계산 기준

1. 세 플랫폼의 공개 이벤트 상세에서 실제 선택 옵션, 1회 가격, 부위, 용량(cc)·샷 수·관리 시간, 장비/제제, 부가세, 적용 조건과 관측일을 확인한다. 목록의 '최저 ~'만 보고 숫자를 가져오지 않는다.
2. 같은 장비/제제·부위·용량·횟수·포함 관리·이용 조건인 자료만 같은 `basis`에 묶는다. HIFU 샷 수, PN/HA 용량, RF 장비, 필링 종류가 다르면 합치지 않는다. 1회 금액이 명시되지 않은 패키지, 가격·부가세·단위를 확인할 수 없는 이벤트는 제외한다. 첫 방문·회원 한정 등 조건이 있으면 동일 조건으로 구분하고 `basis`에 표시한다.
3. 동일 제공자의 동일 시술·옵션이 여러 플랫폼에 중복되면 한 표본으로 취급한다. `sampleKey`는 이 동일성 확인 후 만든 SHA-256 식별값이다. 병원 이름·의료진·연락처를 앱 필드에 추가하지 않는다. 동일성 확인이 안 되면 중복 가능 표본을 보류한다.
4. 각 표본에 공개 상세 URL, 플랫폼, KRW 정수 금액, 부가세 포함 여부, 한국 날짜 관측일, 동일 조건 `basis`, `sampleKey`를 남긴다. URL이나 문서에 인증 토큰을 저장하지 않는다. 증빙은 실제 열어 확인한 자료만 기록한다.
5. 부가세 별도 금액은 `round(금액 × 1.1)`로 포함 금액으로 통일한다. 키별 가장 최근 자료를 한 번씩 집계한다. 같은 날짜의 같은 키에서 금액/부가세가 충돌하면 계산을 중단하고 원문을 재확인한다.
6. 평균은 `round(고유 표본 금액 합 / 표본 수)`, 범위는 해당 표본의 최저·최고다. 횟수가 확인되지 않은 공개 상품은 1회 금액으로 환산하지 않고 명시된 용량/샷 수 단위로만 구분한다. 표본 수·플랫폼·관측 기간·조건·부가세 기준을 함께 표시한다. 작은 표본도 표본 수를 숨기지 않는다. 이 이벤트 표본은 할인·지역·플랫폼 편향이 있으므로 **수집 표본 평균**이며 전국 평균·적정가로 일반화하지 않는다. 원래 스펙의 전국 평균 표시는 근거가 확보될 때까지 미충족이다.

## 로컬 준비와 가격 반영

기존 샘플 시드와 별도다. 다음 명령은 포트 55432의 로컬 `sikin_dev`/`sikin_test`만 허용한다. 이미 있는 코드의 내용·가격을 시드로 덮어쓰지 않는다.

```sh
npm run db:up
npm run db:generate
npm run db:migrate
npm run procedures:seed
```

실제 수집 후 JSON 파일에 `{ code, basis, observations }`를 작성한다. `code`는 `prisma/seeds/procedures.ts`의 코드다. `observations` 각 항목은 아래 필드를 모두 가져야 한다. 가격을 추측해 채우지 않는다.

| 필드          | 의미                                                   |
| ------------- | ------------------------------------------------------ |
| `platform`    | `GANGNAMUNNI`, `YEOSHIN`, `BABITALK`                   |
| `sourceUrl`   | 해당 플랫폼에서 직접 확인한 공개 HTTPS 상세 URL        |
| `sampleKey`   | 동일 제공자·시술·옵션을 구분하는 64자리 소문자 SHA-256 |
| `amountKrw`   | 명시된 1회 금액, 양의 정수                             |
| `vatIncluded` | 확인한 부가세 포함 여부, boolean                       |
| `observedOn`  | 한국 날짜 `YYYY-MM-DD`, 미래 날짜 불가                 |
| `basis`       | JSON 최상위 basis와 정확히 일치하는 시술 조건          |

```sh
# 조회·검증·집계 미리보기만 수행, 저장하지 않음
npm run procedures:prices -- /tmp/collected-procedure-prices.json
# 검증된 자료를 로컬 DB에 반영
npm run procedures:prices -- /tmp/collected-procedure-prices.json --apply
```

오류가 있으면 저장하지 않는다. 기존 API 프로세스 캐시는 최대 30초 후 새 자료를 읽는다. 기존 숫자 가격 열은 하위 호환을 위해 남겨 두지만, 공개 가격은 증빙 표본에서만 계산한다. 원격 반영 명령이나 자동 수집·예약 연동은 추가하지 않았다.

## 세 플랫폼 추가 반영 후 검증

- 새 환경에서 `unni.app`와 `web-api.babitalk.com`의 enforced 허용과 HTTP 200을 확인했다. 추가 네트워크 변경 없이 정상 TLS 검증으로 수집했다.
- 기존 여신티켓 자료와 커밋을 유지하고 새 6건을 추가했다. 21건/고유 20표본이며, PN 6표본 평균은 246,817원(162,000~319,000원), RF 4표본 평균은 277,775원(264,000~297,000원)이다. PN/RF는 명시된 상품 용량·샷 수 기준이며 1회 총비용으로 환산하지 않았다.
- `npm run test`: 237개 통과. 새 강남언니 정식 호스트 수용 및 위장 호스트 거부, 세 플랫폼 증빙 연결, 횟수 미확인 상품을 1회로 표시하지 않는 조건을 검증했다.
- `npm run test:db`: 139개 통과.
- `npm run lint`, `npm run typecheck`, `npm run format:check`, 변경 파일 Prettier 검사, `npm run build`: 통과.
- `npm run test:e2e -- tests/procedures.spec.ts`: 7개 통과. 320px·1280px 화면과 320px PN 세 플랫폼 출처/평균/확인 필요 문구를 실제 렌더링·캡처로 확인했다.
- 정상 기능과 실제 자료 반영은 검증했지만, 전국 시장 대표성 및 일부 상품의 정확한 횟수·총비용은 미확인이다. 이 범위의 인수 기준을 완료한 것으로 처리하지 않고 보드 review 상태를 유지한다.
- 공개 배포·push·환경 게시·기존 환경 삭제 없음. `8b4c542` 원본은 미복구 상태 유지.
